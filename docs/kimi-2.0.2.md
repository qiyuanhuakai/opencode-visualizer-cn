# Kimi Code 2.0.2 适配检查（2026-09-22）

本轮基于本机 `kimi --version` 输出 `2.0.2`、运行中的 REST/OpenAPI/AsyncAPI、真实 WebSocket 事件及 VIS 浏览器交互检查。`docs/kimi.md` 的 0.43.0 调研保留为历史记录；本页记录本轮改动和验证边界。

## 修复

- 沙盒树保持 workspace → directory/branch → session 的稳定身份。Git 标签变化不再重建归属；迁移清除旧目录副本；读取完整会话分页。独立 child 会话通过 `parent_session_id` 归属父会话，同会话运行的 agent/task 不冒充独立会话。
- 新建会话先写 profile、登记树，再发布选中状态。旧异步响应不覆盖后续选择。初始化跳过归档及子会话作为默认选择；空工作区也建立消息连接。
- 恢复共享提供商／模型管理标签、模型显隐及配置变更通知；支持 2.0.2 的 `display_name`、catalog 形状、`image_in`／`video_in`／`tool_use` 和思考力度目录。
- UI 的提供商／模型组合 ID 与 Kimi 的原始模型别名分离。创建及发送写原始别名；发送前等待 model/thinking 配置，失败保留草稿。
- `prompt.submitted` 实时登记用户消息，回复绑定真实用户消息 ID；不靠重新加载历史补齐。卡片按用户根消息保持身份，只有首次回复淡入，支持减少动态效果。选中行不改变几何尺寸。
- 处理 2.0.2 新增 `subagent.cancelled`，终结子代理输出。全局及其他会话的创建、标题、归档、删除、忙闲事件原位更新会话树。

## 功能入口

| 功能 | 入口及行为 |
| --- | --- |
| 账户额度、上下文 | 状态监视器 Token 页：5 小时／7 天额度、重置时间、上下文已用与上限；实时状态更新 |
| 会话目标 | 会话菜单：读取／设置、暂停、恢复、取消；展示服务器状态及用量。恢复会继续运行并消耗模型额度 |
| 插件 | 状态监视器 Plugins 页：来源安装、市场、启用／禁用、确认移除；区分错误与空列表 |
| 子智能体管理 | 会话菜单：独立子会话创建／打开、模型／思考／权限设置；同会话子代理任务独立展示和停止 |
| 会话操作 | 底部菜单中整会话复制、压缩与子智能体管理；底部线程目标；会话固定、重命名、归档、恢复及归档搜索；消息卡片内分支、差异、撤销 |

## 验证边界

完整测试 3,294 项通过、6 项跳过；类型检查及构建通过。真实 2.0.2 发送、会话操作、目标和额度读取均执行；界面在 375／768／1280 宽度检查。插件安装／删除和运行任务取消以可控 fixture 验证，未改动用户插件或取消用户任务。测试使用独立会话，结束后已清理本轮创建的会话和临时服务。

- 消息卡片分支先复制整会话，再在副本内撤销所选消息及后续轮次；撤销只回退会话上下文，不恢复磁盘文件。差异读取该轮文件快照；跨压缩检查点的撤销由界面拒绝。
- 底部上拉菜单保留原始 `manual`／`auto`／`yolo` 和 `plan`／`swarm`／`tower` 名称。支持 `/help`、权限／模式切换、`/compact` 以及原有本地 `/shell`、`/debug`；没有 Web 执行接口的 TUI 命令明确提示不支持。
- 隐藏文件和 Git 忽略文件现在进入文件树。Token 模型名及上下文以会话状态为准，累计用量取实时累计值或会话快照；额度与插件采用状态监控主题样式。
- 空或不足以压缩的上下文可能返回业务错误 `40910`，界面显示后端拒绝，不冒报成功。
- 2.0.2 实测外部 REST restore 不广播恢复事件；VIS 本地恢复立即更新，其他客户端恢复需刷新／重连。
- 分支、压缩与撤销入口在当前连接的 meta/auth 检查及随机不存在会话的安全路由探测成功后才展示；断线或连接切换会清除探测结果。
- Tower 仍受后端实验标志限制；未把协议中出现的所有功能一概声明可用。
- Shell 经 VIS 桥接层的 PTY 接口运行；Kimi 原生终端在本机因 `pty.node` 加载失败而不可用。未执行过轮次的会话显示灰色空心圆，完成轮次后才显示 Idle。
